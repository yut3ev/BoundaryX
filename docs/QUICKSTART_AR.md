# BoundaryX — دليل التشغيل السريع (Quickstart)

منصة أبحاث واختبارات أمن الويب المصرّح بها (Authorized Web Security Research Workbench).

---

## 1. المتطلبات الأساسية للنظام

- **نظام التشغيل**: Linux (Ubuntu 24.04 / 22.04 LTS x86_64) أو Windows 10/11 أو macOS (Apple Silicon / Intel).
- **Python**: الإصدار 3.12 أو أحدث (موصى به عبر أداة `uv`).
- **Node.js**: الإصدار 20 LTS أو أحدث مع `npm`.
- **Rust**: الإصدار المستقر `stable` (مطلوب فقط لبناء غلاف Tauri من المصدر).

---

## 2. خطوات التثبيت والتشغيل المحلي

### أ. إعداد المحرك البرمجي (Python Engine)
```bash
# الانتقال لمجلد المحرك
cd engine

# تثبيت الاعتماديات بوضع التطوير
pip install -e ".[dev]"

# تشغيل حزمة الاختبارات الكاملة للتأكد من السلامة
pytest tests/ -v

# تشغيل المحرك في وضع IPC Sidecar (للتواصل مع واجهة سطح المكتب)
python -m boundaryx.cli --ipc
```

### ب. إعداد واجهة سطح المكتب (Desktop Workbench)
```bash
# الانتقال لمجلد واجهة المستخدم
cd apps/desktop

# تثبيت الاعتماديات
npm install

# التحقق من خلو الأنواع من الأخطاء وبناء النسخة الإنتاجية
npm run build

# تشغيل الواجهة في وضع التطوير المحلي
npm run dev
```

## 3. ميزات الأمان ونطاق الفحص (Scope Guard)

1. **التحقق الصارم من النطاق (Scope Boundaries)**:
   - يمنع المحرك تلقائيًا أي طلبات موجهة لنطاقات خارجية أو هجمات الخداع المعتمدة على اللاحقات أو السوابق (مثل `evil-target.com`).
   - يدعم تحويلات IDNA/Punycode لحماية المنظومة من هجمات التماثل البصري (Homograph Attacks).
   - يعترض كل قفزة في سلاسل إعادة التوجيه (Redirect Hops) ويمنع الخروج عن النطاق المصرّح به.

2. **عزل وتشفير الأسرار (Secret Vault)**:
   - لا يتم حفظ مفاتيح API (مثل Google Gemini) بنص صريح إطلاقًا داخل قواعد البيانات أو السجلات.
   - يتم التشفير محليًا عبر مكتبة Fernet ومستودع المفاتيح الآمن للنظام (OS Keyring).

3. **الربط مع Google Gemini (اختياري)**:
   - يتطلب موافقة صريحة من المستخدم قبل إرسال أي محتوى للتحليل.
   - تُحجب تلقائيًا رموز التفويض (Tokens) وملفات تعريف الارتباط (Cookies) قبل إرسال السياق للذكاء الاصطناعي.
   - يتحقق المحرك من مراجع الأدلة ولا يقبل أي استنتاجات لا ترتبط بأدلة فحص حقيقية مخزنة.

---

## 4. استخراج التقارير وتصدير الأدلة

يدعم التطبيق تصدير التقارير بأربعة تنسيقات متوافقة مع متطلبات المراجعة والتدقيق الأمني:
- **Markdown**: للمعاينة السريعة والتوثيق المكتبي.
- **HTML (مستقل ومحصن)**: مجهز بحماية XSS وخالٍ من الاعتماديات الخارجية.
- **CSV محصن**: مزود بحماية كاملة ضد حقن المعادلات الرياضية (Formula Injection Defense).
- **JSON منظف ومحجوب**: لربطه بأنظمة الـ SIEM وأدوات الأتمتة الأمنية.
